เครื่องมือและขั้นตอนตัดคลิป BBN

ชุดตัดคลิป BBN ใช้ Codex วางแผนตัด + โมเดลถอดเสียงบนเครื่อง + FFmpeg ตัดและส่งออก + HyperFrames ทำกราฟิก
ข้อมูลนี้ตรวจจากคู่มือที่ติดตั้งและสคริปต์ EP224

1. ดึงไฟล์ต้นฉบับ
เครื่องมือ: rclone ผ่าน SSH
หน้าที่: ดาวน์โหลดฟุตเทจจาก Google Drive และตรวจขนาด/แฮช

2. ตรวจไฟล์
เครื่องมือ: FFprobe
หน้าที่: อ่านความยาว ความละเอียด FPS และแทร็กเสียง

3. แยกเสียงออกจากวิดีโอ
เครื่องมือ: FFmpeg
หน้าที่: สร้าง WAV 16 kHz mono สำหรับวิเคราะห์ และเก็บเสียง 48 kHz แยกสำหรับงานตัดต่อ

4. หาช่วงพูดและช่วงเงียบ
เครื่องมือ: Silero VAD ผ่าน faster-whisper / ONNX Runtime
หน้าที่: แบ่งช่วงเสียงก่อนถอดคำพูด พร้อมตรวจระดับเสียงด้วย waveform/RMS

5. ถอดเสียงไทยเป็นข้อความ
เครื่องมือ: Qwen3-ASR-1.7B BF16 ผ่าน MLX Audio
หน้าที่: ถอดคำพูดจริง รวมคำซ้ำ การพูดผิดและพูดใหม่ แบ่งเสียงช่วงละไม่เกิน 30 วินาที

6. ตรวจคำที่ไม่ชัด
เครื่องมือ: Whisper large-v3-turbo ผ่าน mlx-whisper
หน้าที่: ตรวจซ้ำเฉพาะช่วงสงสัย มี Thai Whisper ของ biodatlab/Thonburian เป็นตัวสำรอง

7. หาตำแหน่งคำเพื่อวางจุดตัด
เครื่องมือ: Typhoon Whisper Thai CTC + encoder คู่กัน
หน้าที่: จับข้อความที่ตรวจแล้วเข้ากับเสียง จากนั้นตรวจ waveform อีกครั้งก่อนตัด ใช้เฉพาะจุดที่ต้องการเวลาละเอียด

8. ซิงก์กล้องกับหน้าจอ
เครื่องมือ: Python + NumPy + SciPy cross-correlation
หน้าที่: เทียบเสียงหลายตำแหน่งเพื่อหาเวลาคลาดและตรวจการเหลื่อมตลอดคลิป

9. เลือกว่าจะตัดอะไร
เครื่องมือ: Codex/GPT + transcript + ภาพหน้าจอ + waveform
หน้าที่: เลือกตัดคำซ้ำ พูดใหม่ รอโหลด และคำสั่งถึงคนตัด โดยรักษาประโยคและเดโมให้ครบ

10. สร้างแผนตัดกลาง
เครื่องมือ: Python / JSON edit plan + compile_edit_plan.py
หน้าที่: ระบุช่วงเฟรมที่เก็บไว้ แล้วใช้แผนเดียวกับภาพกล้อง หน้าจอ เสียง และคิวกราฟิก

11. จัดภาพและปิดข้อมูลส่วนตัว
เครื่องมือ: FFmpeg
หน้าที่: ครอป จัดหน้าจอ วางหน้าผู้พูดวงกลม ย่อ/ขยาย และเบลอเฉพาะข้อมูลที่อ่านได้

12. ปรับและผสมเสียง
เครื่องมือ: FFmpeg + NumPy/SoundFile
หน้าที่: ทำ fade รอยตัด ปรับเสียงพูดด้วย highpass/loudnorm ผสมเพลงกับ SFX และจำกัด peak; ใช้ afftdn เมื่อต้องลด noise

13. ทำข้อความและแอนิเมชัน
เครื่องมือ: HyperFrames + GSAP
หน้าที่: ทำข้อความเข้า–ค้าง–ออกตามคำพูด แล้วนำกราฟิกมาประกอบกับคลิปด้วย FFmpeg

14. ทำ Short และซับ
เครื่องมือ: FFmpeg + ASS/libass
หน้าที่: จัดภาพแนวตั้ง 9:16 หน้าจอบน–ผู้พูดล่าง ใส่ซับตามเวลา ใช้ Canva Sans ตามข้อกำหนด และตรวจตัวอักษรไทยในไฟล์จริง

15. ส่งออกคลิป
เครื่องมือ: FFmpeg + Apple VideoToolbox
หน้าที่: เข้ารหัสภาพ H.264 ด้วย h264_videotoolbox และเสียง AAC เป็น MP4

16. ตรวจไฟล์ก่อนส่ง
เครื่องมือ: FFprobe + FFmpeg + สคริปต์ Python + ตรวจภาพ/เสียงจริง
หน้าที่: ตรวจความยาว ซิงก์ รอยตัด ซับ ข้อมูลส่วนตัว ความชัด และระดับเสียง

17. ส่งมอบ
เครื่องมือ: rclone + Hermes / bbn-video-queue + Telegram bot
หน้าที่: อัปโหลด Google Drive ตรวจไฟล์ปลายทาง แล้วส่งลิงก์ตรวจงานตามสิทธิ์ที่ได้รับ

เรื่องการแปลภาษา

ขั้นตอนปัจจุบันเป็นการถอดเสียงไทยเป็นข้อความไทย ยังไม่มีขั้นตอนแปลเป็นภาษาอื่นเป็นค่าเริ่มต้น
Qwen ในสคริปต์ตั้งภาษาเป็น Thai และ Typhoon CTC ใช้จับเวลา ไม่ได้แปลภาษา
ข้อความบนคลิปและซับคือการเรียบเรียงจากคำพูดในตอนนั้น

งานครบชุดเพิ่มเติม

ใช้ bbn-youtube-tags → bbn-youtube-title → bbn-youtube-description สำหรับแพ็กข้อความ
ใช้ bbn-youtube-thumbnail สำหรับภาพปก
ส่งงานตามลำดับ Long → Package → ภาพปก → Short
