# Short แบบ teaser และการแก้การ์ดท้าย

ใช้เมื่อเจ้าของช่องขอคลิปชวนดู Long หรือแก้ CTA/ข้อความท้ายของ Short ที่ส่งแล้ว คำสั่งล่าสุดชนะค่าเริ่มต้น tutorial และข้อห้ามชื่อรุ่นเก่า

## เลือกเนื้อหาจาก EP ที่ถูกต้อง

- ล็อกเลข EP, ชื่อรุ่น, Drive folder/file ID, source hash และความยาวจากบรีฟล่าสุดก่อนตัด เมื่อผู้ใช้แก้เลข EP ให้เปลี่ยนแหล่งภาพ/เสียง/ข้อความทั้งหมดตามตอนที่ถูกต้อง อย่านำอีกตอนมาตั้งชื่อใหม่
- Teaser ใช้ hook → ประเด็นหรือประโยชน์ที่น่าสนใจไม่กี่ข้อ → คำชวนไปดู Long ไม่ใส่ benchmark ราคา ขั้นตอน หรือเนื้อหาจนเล่าแทน Long ทั้งหมด เว้นแต่บรีฟขอ
- ใช้คำพูดที่บันทึกไว้จริง ตัดประโยคให้ครบ ไม่เร่งเสียงเพื่อยัดข้อมูล และไม่สร้างคำพูดใหม่จากข้อความ CTA หากขอประมาณ 45 วินาที ให้วางแผนให้ใกล้ 45 วินาทีรวมการ์ดท้ายและ music tail
- ดึงภาพ/ผลลัพธ์จริงจาก Long ของตอนนั้นตามคำพูด ช่วงอธิบายที่ไม่มีภาพรองรับทำ motion ที่สื่อแนวคิดตาม ref ได้ ไม่วาด mock UI หรือผลลัพธ์ที่อ้างว่าทดลองจริง ดู ref ที่ส่งจริงก่อนตัดสินสี จังหวะและเลย์เอาต์; อย่าใช้ชื่อ EP เป็นหลักฐานสไตล์
- ยังคง cutout เฉพาะ hook และกล้องพร้อมห้องเดิมครึ่งล่างของ narrated body ตาม SKILL.md การ์ดท้ายที่ไม่มีเสียงพูดใช้เต็มจอได้โดยไม่สร้างผู้พูดเพิ่ม

## เพลงต้องมีทั้งใน assets และเสียง export

ใช้เพลงที่เจ้าของช่องให้หรืออนุญาตจริง คัดลอกไฟล์เพลงเข้า editable project's assets พร้อมแหล่งที่มาและ hash; อย่าเก็บเพียงพาธบนเครื่องคนตัด ทำให้ preview และ export ใช้ master เดียวกัน รักษาเสียงพูดชัด ลดเพลงใต้เสียงและจัด fade/tail ตามจังหวะคลิป ไม่ถือว่าอ้างชื่อเพลงในเอกสารหรือมี audio stream คือใส่เพลงแล้ว

ตรวจไฟล์เพลงในชุดส่งจริง, stem/master และ final encode รวมช่วงเงียบที่ควรได้ยินเพลงกับระดับที่วัดได้ ระบุว่าฟังจริงหรือใช้ waveform/loudness/ASR; อย่าเรียกค่าที่วัดว่าได้ฟัง หากส่ง project ZIP ต้องมีเพลงต้นฉบับและทุก media dependency ของ composition อยู่ในชุด

## CTA ยึดข้อความที่สั่ง

- ใช้ถ้อยคำและ keyword ตามผู้ใช้ เช่น `คอมเมนต์ Gemini เดี๋ยวส่งคลิปเต็มให้ครับ` เป็นข้อความของงานที่ขอ Gemini เท่านั้น ไม่ใช่ CTA สำเร็จรูปทุก EP
- การขอเปลี่ยนข้อความท้ายคือแก้ภาพ ไม่ได้อนุญาตโคลนเสียงหรือเพิ่ม spoken line ใช้เสียง/เพลงเดิมเมื่อไม่ได้สั่งแก้เสียง
- ถ้าผู้ใช้เอาป้ายล่างออก ให้ลบ layer นั้นจาก compositor และ build script จริง ไม่ปิดทับเฉพาะ MP4 และไม่เติมชื่อรุ่น/เลข EP/production note กลับเข้าไปเอง รักษาข้อความ CTA ที่เหลือ
- รักษาโลโก้หรือเนื้อหานอกขอบเขตที่ไม่ได้สั่งแก้ ตรวจตัวสะกด สระ/วรรณยุกต์ การขึ้นบรรทัด entrance/hold/exit และ seam จากไฟล์ที่ encode แล้ว

## แก้เฉพาะช่วงและส่งรุ่นเดิมต่อ

ยึด [focused visual revisions](../../bbn-ai-cut/references/focused-visual-revisions.md): archive ไฟล์รับรองก่อนแก้, ระบุช่วงเฟรมครึ่งเปิด `[start_frame,end_frame)`, รักษาเวลา/ภาพนอกขอบเขต และคัดลอก soundtrack เดิมครบทั้ง packet payload และ timestamps รวมปลายเพลง ถ้า splice วิดีโออย่างปลอดภัยไม่ได้ ให้ encode วิดีโอใหม่แล้วรายงานตามจริง ไม่อ้าง video packet identity ตรวจ frame count/PTS/full decode และเทียบภาพช่วงเดิมตามวิธีที่ใช้

อัปเดตทั้ง composition เต็มและ build script แม้เรนเดอร์เฉพาะท้าย ตรวจภาพจาก final MP4 และทำ project ZIP ใหม่ให้ตรง export ใช้ QA ของส่วนที่ไม่เปลี่ยนต่อได้ ไม่ถอดเสียงทั้งตอน/มิกซ์เสียงใหม่/เรนเดอร์ซ้ำโดยไม่มีข้อผิดพลาดใหม่

ค่าเริ่มต้นคือชื่อและ Drive ID เดิม หากผู้ใช้ขอ `v2` โดยตรง ให้สร้างรุ่นนั้นแยกหนึ่งครั้ง แล้วทุก correction ต่อจากรุ่นนั้นอัปทับไฟล์ `v2` ชื่อเดิม ID เดิม ไม่สร้าง `v3` เอง ตรวจ remote state ก่อนแทนและเทียบ ID/size/hash หลังอัป ก่อนบอกว่าส่งสำเร็จ เก็บต้นฉบับ Long/Short ไว้ ไม่เปลี่ยน sharing หรือโพสต์ social จากคำขอแก้คลิป
