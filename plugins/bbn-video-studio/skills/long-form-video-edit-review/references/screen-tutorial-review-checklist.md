# Screen-tutorial review checklist

## Artifact

- [ ] Correct long-form item/episode and version
- [ ] Excluded TK/Short/proxy/raw files
- [ ] Duration, dimensions, codecs, frame rate and size recorded

## Technical

- [ ] Full decode succeeds
- [ ] Black frames and final tail checked
- [ ] Static/freeze detections visually interpreted
- [ ] Contact sheets cover the complete timeline
- [ ] Suspect intervals sampled more densely

## Audio

- [ ] Integrated loudness and true peak measured
- [ ] Mean/max volume measured
- [ ] Silence/low-activity intervals checked
- [ ] Local transcript aligned when available
- [ ] `no detected speech` not mislabeled as digital silence

## Editing

- [ ] Hook and time-to-value
- [ ] Repetition and prior-episode references
- [ ] Loading/skeleton/waiting screens
- [ ] Static screens relative to narration
- [ ] False ending before promo
- [ ] Promo/outro duration and CTA
- [ ] Final frame and black tail

## Privacy

- [ ] Browser tabs/address/local path
- [ ] Hostname/IP/server/account/order/payment
- [ ] Workflow ID/name/credentials/endpoints
- [ ] Sessions/prompts/profile/notifications
- [ ] QR/pairing/OTP/auth state across full interval

## Reporting

- [ ] One upload-readiness decision first
- [ ] Must-fix defects separated from editorial advice
- [ ] Exact timestamps and measured values included
- [ ] Secrets categorized but never transcribed
- [ ] Read-only status stated unless an edit was explicitly authorized
