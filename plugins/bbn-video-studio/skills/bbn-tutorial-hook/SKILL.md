# BBN Tutorial Hook & Cover

## การใช้ใน workflow ของ auto-post-content

สำหรับ Short เลือกเสียงฮุคที่บันทึกจริงและ highlight/final output จาก Long ของตอนนั้น แล้วใช้ bbn-ai-short-fullscreen คุมภาพเต็มจอและผู้พูด cutout เฉพาะฮุคเปิดตามกติกาเจ้าของช่องล่าสุด หลังฮุคคืนเทมเพลต 50/50 หน้าจอบน–ผู้พูดล่างจากกล้องจริงพร้อมห้องเดิม ไม่ไดคัตคน และใส่ประโยคเสียงจริงที่บอกว่าจะสอนเรื่องอะไรก่อนเริ่มบทเรียน หากฮุคผ่านแล้วห้ามเลือกหรือสร้างใหม่เมื่อผู้ใช้แก้เฉพาะเนื้อหา ไม่ยก +/VS มาทับกฎโลโก้ fullscreen ส่วนเทมเพลตปกแนวตั้งใช้เมื่อขอปกชนิดนั้น ไม่เปลี่ยนปก YouTube 16:9 พาธ panda เป็น provenance; ตรวจ runtime ปัจจุบันก่อนใช้

สร้างฮุคก่อนเข้าสอนที่ทำให้ผู้ชมเห็น **ผลงานที่จะทำได้และเหตุผลที่ควรดูต่อ** พร้อมหน้าปกจากเนื้อหาจริง ใช้กับทุกแอปและหัวข้อของบทเรียน ไม่ยึดชื่อแอปในตัวอย่าง

อ่าน [เทมเพลตและภาษาภาพ](references/layouts.md) เมื่อจัดภาพ และ [การเลือกเนื้อหา เวลา และส่งงาน](references/hook-workflow.md) เมื่อตัดฮุคหรือทำปก SVG ใน assets เป็น role guides ที่แก้ไขได้ ไม่ใช่ภาพพร้อมเผยแพร่

## ข้อตกลงของผู้ใช้

- **วิดีโอฮุค:** พื้นที่บนตามเทมเพลตสีแดงใช้ highlight หรือ final output ของสิ่งที่สอนทำเสร็จ พื้นที่ล่างตามสีเหลืองใช้คลิปผู้พูด ทั้งสองอยู่ให้เห็นพร้อมกัน
- **หน้าปก:** โลโก้แอปอยู่ด้านบน Name Hook อยู่ใต้โลโก้ ผู้สอนจริงตัดพื้นหลังและขยายใหญ่ที่ครึ่งล่าง ศีรษะคาบรอยต่อได้แต่ไม่บังชื่อฮุค/โลโก้
- สีแดง/เหลืองกำหนดบทบาทและตำแหน่งของพื้นที่ ไม่บังคับทาสองสีนี้ลงในภาพจริง รูปผลงาน/ผู้พูดมาแทนพื้นที่นั้น; หากบรีฟต้องการพื้นสีดังกล่าวให้ใช้ตามบรีฟ
- `Name Hook` คือหัวข้อสั้นที่เขียนจากประโยชน์หรือผลงานของคลิป ไม่ใช่คำว่า NAME HOOK ที่พิมพ์ลงปกจริง `LOGO Learning`, `Speaker`, `highlight/final Outputs` เป็น placeholder ที่ต้องแทนหรือเอาออก

## เลือกรูปแบบโลโก้

| เนื้อหาของคลิป | รูปแบบ |
|---|---|
| สอนหนึ่งแอป | โลโก้จริงหนึ่งอัน กลางด้านบน |
| ใช้สองแอปร่วมกัน/ส่งงานต่อกัน | โลโก้ซ้าย **+** โลโก้ขวา |
| เปรียบเทียบสองแอป | โลโก้ซ้าย **VS** โลโก้ขวา |

ใช้ความสัมพันธ์จากบทเรียน ไม่ใช้ VS เพียงเพราะมีสองแอป และไม่ใช้ + แทนคลิปเปรียบเทียบ เลือกแอปหลักที่เรียนจริง ไม่ใส่ทุกแอปที่เผลอกล่าวถึง หากมีมากกว่าสองแอปที่จำเป็น ให้จัดลำดับ/กลุ่มโลโก้ตามบรีฟโดยไม่ลดจนอ่านไม่ออก

## วิธีทำ

1. อ่านบรีฟและแผนตัดต่อเดิม หาเนื้อหาที่สอน ผลงานสำเร็จที่มีหลักฐาน แอปที่ใช้ ความสัมพันธ์ของแอป ฟุตเทจฮุค/เสียงผู้พูด และ portrait หรือเฟรมผู้สอนจากตอนปัจจุบัน ใช้ source→final mapping เดิม
2. เลือกผลงานที่เห็นผลได้ทันที แล้วเขียน Name Hook หนึ่งชื่อที่ตรงบทเรียน ปกมักไม่เกินสองบรรทัดสั้น ไม่เติมข้ออ้าง เช่น ฟรี/เร็วที่สุด/เสร็จในหนึ่งคลิก โดยไม่มีหลักฐาน แยกหัวข้อบนภาพออกจากประโยคฮุคที่ต้องพูดจริง
3. สำหรับ Short ใน auto-post-content ใช้ฮุคเต็มจอกับผู้พูดวิดีโอ cutout ตาม bbn-ai-short-fullscreen รักษาเสียง/สีหน้า/ลิปซิงก์จาก take จริงและคงฮุคที่ผ่านแล้วเมื่อแก้เฉพาะเนื้อหา เทมเพลตผลงานบน–คนล่างของสกิลนี้ใช้เฉพาะเมื่อบรีฟขอ split hook โดยตรง โลโก้/ข้อความอ่านได้ ไม่บังผลงาน entrance/hold ตรงเสียง ไม่เด้งทุกองค์ประกอบ
4. ทำปกจากโครงที่ตรงชนิดบทเรียน ใช้ผู้สอนที่ผู้ใช้เลือกหรือเฟรมชัดจากผู้สอนในตอนนั้นตามบรีฟ ตัดพื้นหลัง ขยายโดยรักษาสัดส่วนและตัวตน จัดโลโก้กับ Name Hook ให้ครบ ใช้ผู้สอนในเทมเพลตเป็นตัวอย่างการจัดวาง ไม่เอารูปคนเดิมไปใช้กับทุกตอน
5. จบฮุคตามประโยคที่สมบูรณ์ แล้วกลับไปคลิปอัดหน้าจอและเลย์เอาต์สอนเดิมตั้งแต่เริ่มสอน ไม่ค้างปก/ชื่อฮุค/โลโก้ชุดฮุคมาบังช่วงสอน เสียงและการเคลื่อนที่ของผู้พูดต่อเนื่องตามแผนตัด
6. ตรวจ preview ที่ encode แล้วและปกที่ขนาดจอโทรศัพท์ ก่อนส่งไฟล์จริงพร้อมซอร์สแก้ไขได้/ข้อมูล cue ตามขอบเขตที่ขอ

## เครื่องมือและขอบเขต

ใช้ editor/runtime ที่มีอยู่ เช่น HyperFrames/GSAP กับ FFmpeg สำหรับวิดีโอ อ่านสกิลของเครื่องมือเมื่อใช้จริง runtime guide อยู่ที่ `~/.local/share/bbn-ai-cut/README.md` และ `env.sh` ข้างกัน (ตรวจว่ามีจริงบนเครื่องนี้) ไม่ติดตั้ง engine ใหม่โดยไม่จำเป็น

เมื่อแก้ภาพนิ่ง/ตัดพื้นหลัง/สร้างปก ใช้ `imagegen` และเครื่องมือ image generation/editing ที่มี โดยแนบ asset ตามบทบาทและตรวจภาพที่ได้จริง รักษาตัวตนของผู้สอนและรูปโลโก้ ถ้ามี cutout ที่รับรองแล้วใช้ของเดิมได้ การตัดพื้นหลังผู้พูดในปกไม่ใช่คำสั่งให้ตัดพื้นหลังวิดีโอผู้พูดทั้งฮุค

สกิลนี้กำหนดปกแนวตั้งตามเทมเพลตล่าสุด ไม่เปลี่ยนค่าเริ่มต้นของสกิลปก YouTube แนวนอนอื่น หากขอ 16:9 ให้จัดใหม่ตามพื้นที่ ไม่ยืดปก 9:16 เมื่อขอเฉพาะปก/ข้อความ/ฮุค ให้ทำเฉพาะสิ่งนั้น ไม่เริ่ม full edit, Long/Short เพิ่ม, เปลี่ยนเสียงทั้งเรื่อง หรือเผยแพร่เอง

## ตรวจรับ

ผลงานบนฮุคเป็นผลงานจริงของบทเรียน ชื่อฮุคตรงประโยชน์ โลโก้/+ /VS ถูกประเภท ฟอนต์ไทย/วรรณยุกต์ครบ ผู้สอนไม่เปลี่ยนหน้าตาหรือถูกยืด ขอบ cutout สะอาด ไม่มี placeholder/player controls/ขอบอัดหน้าจอหลงมา และช่วงสอนกลับใช้หน้าจอจริงตรงเฟรม ตรวจไฟล์ที่ส่งจริง ไม่อ้างว่าเรนเดอร์แล้วจาก storyboard หรือ HTML preview
