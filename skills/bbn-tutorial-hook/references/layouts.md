# เทมเพลตฮุคและปก

## หลักฐานอ้างอิงและสิ่งที่เป็นการออกแบบเพิ่ม

ผู้ใช้ส่ง screen recording วันที่ 2026-10-08 ความยาวประมาณ 14.98s และ role templates แนวตั้งสี่ภาพในวันที่ 2026-10-09 คลิปมีเพียง video stream จึงไม่ได้ยืนยันถ้อยคำฮุค จังหวะคำ หรือเสียงประกอบจากไฟล์นี้

จากภาพที่สุ่มตรวจทุกประมาณ 1s: ช่วงต้นถึงราว 4s มีผลงาน MV ด้านบน โลโก้ Claude และหัวข้อ “สร้าง MV ง่าย / ด้วย Claude” ผู้พูดอยู่ล่าง โดยราว 5s เปลี่ยนด้านบนเป็นหน้าจอแอปเพื่อเข้าสอน และผู้พูดล่างเห็นตัวมากขึ้น ภาพห้องยังอยู่ในวิดีโอ คลิปตัวอย่างมี browser/player และเครื่องมืออัดหน้าจอติดมา ซึ่งไม่ควรถือเป็นองค์ประกอบสำหรับสร้างงานใหม่

นี่เป็นการตรวจภาพตามเวลา ไม่ใช่การวัดเส้นโค้ง animation หรือเฟรมเปลี่ยนฉากอย่างแม่นยำ ระยะฮุคจริงเลือกจากเสียง/แผนของแต่ละตอน ไม่ใช้ทั้ง 14.98s เป็นฮุคโดยอัตโนมัติ

## ขอบเขตเทมเพลตกับ Short ปัจจุบัน

สำหรับ Short ของ auto-post-content ใช้ bbn-ai-short-fullscreen: ฮุคเต็มจอผู้พูด video cutout เฉพาะตอนเปิด จากนั้นประมาณ 50/50 โมชั่น/หน้าจอจริงบน กล้องพร้อมห้องเดิมล่าง พร้อมประโยคบอกสิ่งที่จะสอนครบ ข้อ A ด้านล่างเป็น template split hook ใช้เฉพาะเมื่อผู้ใช้ขอแบบนั้นโดยตรง ไม่เปลี่ยนฮุคที่รับรองแล้ว การอัปเดตนี้ไม่เปลี่ยนเทมเพลตปกแนวตั้ง B–D

## A. วิดีโอฮุค: ผลงานบน ผู้พูดล่าง

ใช้ [hook-split.svg](../assets/hook-split.svg) เป็นแผนตำแหน่ง เริ่มออกแบบที่ 1080×1920 เมื่อไม่มีขนาดอื่น ใช้ครึ่งบนประมาณ 50% สำหรับ final output/highlight ครึ่งล่างสำหรับผู้พูด ปรับรอยต่อเล็กน้อยได้เพื่อให้ภาพอ่านออก รักษาสัดส่วนทุก source

เลือกผลลัพธ์ที่เห็นความสำเร็จหรือจุดน่าสนใจทันที เช่น คลิปที่ export แล้ว หน้าเว็บที่สร้างแล้ว ภาพที่แต่งเสร็จ เอกสารที่ได้ หรือระบบที่ทำงานจริง ภาพของหน้าเริ่มต้นแอป/ช่อง prompt ว่างยังไม่ใช่ final output ใช้ภาพ/คลิปจริงที่สัมพันธ์กับบทเรียน ไม่สร้างภาพจำลองขึ้นมาอ้างเป็นผลงานเสร็จ

ถ้าผลงานเป็นแนวนอน ให้วาง contain พร้อม backing ที่กลมกลืน หรือครอปเฉพาะเมื่อไม่ทำให้รายละเอียดสำคัญหาย ไม่ stretch เป็นสี่เหลี่ยมสูง หากผลงานมีข้อความ/กราฟ ใช้ช็อตที่อ่านรู้เรื่องบนโทรศัพท์

ผู้พูดเป็นคลิปจริงจาก take ฮุค จัด crop ให้เห็นหน้า/ท่าทางพอเหมาะ ครึ่งล่างมีผู้พูดตามเทมเพลต แต่ไม่จำเป็นต้องตัดพื้นหลังวิดีโอ โดยภาพอ้างอิงยังเห็นห้องเดิม ปกเท่านั้นที่กำหนด cutout เป็นค่าเริ่มต้น

Name Hook บนวิดีโออาจวางทับพื้นที่ผลงานใกล้รอยต่อเมื่อไม่ปิดสิ่งสำคัญ โลโก้อยู่ด้านบนหรือในตำแหน่งที่ไม่บังผลลัพธ์ ใช้หัวข้อใหญ่เส้นขอบขาว/สีตัดพื้นแบบตัวอย่าง ลดองค์ประกอบหากภาพแน่น ไม่ใส่คำว่า Speaker เป็นป้ายให้ผู้สอนโดยไม่จำเป็น

## B. ปกหนึ่งแอป

ใช้ [cover-one-app.svg](../assets/cover-one-app.svg): โลโก้จริงหนึ่งอันกลางด้านบนใน tile มุมมน Name Hook ใต้โลโก้ ผู้สอน cutout ใหญ่ครึ่งล่าง คาบรอยต่อได้ ขยายอย่างรักษาสัดส่วนและปรับให้ทั้งหัวข้อ/โลโก้อ่านครบ

## C. ปกสองแอปใช้ร่วมกัน

ใช้ [cover-two-apps.svg](../assets/cover-two-apps.svg): tile โลโก้สองอันขนาดสมดุลซ้าย/ขวาด้านบน มี **+** ตรงกลาง Name Hook ใต้แถวโลโก้ ผู้สอนใหญ่เหมือนแบบหนึ่งแอป ตัวอย่างความสัมพันธ์คือ ทำวิดีโอด้วย A แล้วทำปกด้วย B ไม่ใช่การแข่งขันระหว่างแอป

## D. ปกเปรียบเทียบ

ใช้ [cover-vs.svg](../assets/cover-vs.svg): โลโก้ซ้าย/ขวาและ **VS** กลาง ต้องเป็นเนื้อหาทดสอบหรือเปรียบเทียบจริง ชื่อฮุคอาจบอกโจทย์/ความต่าง ไม่ประกาศผู้ชนะหากบทเรียนยังไม่มีผลรองรับ

## สัดส่วนสำหรับปกทั้งสามแบบ

ใช้พิกัดสัดส่วนเป็นจุดเริ่มต้น ไม่ล็อกกับขนาด PNG ที่ผู้ใช้ส่ง:

| พื้นที่ | สัดส่วนเริ่มต้น |
|---|---|
| โลโก้บนหนึ่งแอป | กลางภาพ x≈50%, y≈4–22% |
| โลโก้บนสองแอป | ศูนย์กลาง x≈25%/75%, y≈5–23% |
| Name Hook | กึ่งกลางด้านบน y≈24–43%, โดยมาก 1–2 บรรทัด |
| ผู้สอน | ศีรษะเริ่มราว y≈40–45%, ลำตัวเต็มครึ่งล่าง |

เว้น safe margin ราว 5–7% ให้ขนาดโลโก้อ่านได้ ชื่อฮุคใหญ่และสีตัดพื้น ใช้ฟอนต์ไทยที่ตรวจแล้ว เช่น Canva Sans ร่วมกับ Noto Sans Thai รองรับสระ/วรรณยุกต์ ขนาดที่เริ่มลองสำหรับ 1080×1920 คือหัวข้อ 110–150px แล้วปรับตามข้อความจริง ห้ามย่อจนอ่านไม่ออกเพื่อใส่ประโยคยาว

ตรวจช่องว่างและภาพ cutout จริงทุกครั้ง ตัวเลขข้างบนไม่ใช่เหตุผลให้ใบหน้าบังตัวอักษร วางใบหน้าเป็นชั้นหน้าหรือหลังหัวข้อตามกรณีที่อ่านครบ ศีรษะ/ไหล่ใหญ่แบบเทมเพลตแต่ไม่ยืดใบหน้า

## การแทน role guides

SVG เป็นโครงวางพื้นที่ จึงมีสีแดง/เหลืองและชื่อช่องไว้ช่วยออกแบบ **ก่อนส่งงานจริงต้องแทนช่องผลงาน/ผู้พูด/โลโก้/Name Hook และเอาป้าย placeholder/เส้น guide ออก** ไม่ export role guide เป็นหน้าปกเสร็จ

ใช้ไฟล์ผลงานและใบหน้าของตอนปัจจุบัน ส่วนภาพบุคคลในต้นแบบไม่ใช่ portrait ประจำทุกคลิป เก็บ media/portrait/private transcript ในโฟลเดอร์ตอน ไม่คัดลอกเข้าแพ็กสกิลนี้
