# ตัดพื้นหลังวิดีโอผู้พูดและตรวจงาน

## ขอบเขต cutout

ทำ video matting เฉพาะฮุคเปิด เนื้อหาหลังฮุคทุกช่วงที่มี narration รวม topic bridge, explanation, demo, Prompt และ CTA ใช้กล้องจริงพร้อมห้องเดิมครึ่งล่าง ไม่ต้องมี alpha และห้ามลบพื้นหลัง สกิลนี้ไม่กำหนดให้คนโปร่งใสทั้งคลิป ช็อต result-only อาจเต็มจอโดยไม่บังผลงานตาม SKILL.md

## รับ source ที่ถูกต้อง

คนใน foreground ต้องมาจากฟุตเทจวิดีโอที่ผู้ใช้เลือก/ผู้สอนของตอนนั้นและใช้เวลาเดียวกับเสียง ไม่ดึงภาพคนในตัวอย่างไปเป็นผู้พูดทุกตอน ไม่ใช้ cutout ภาพนิ่งจากสกิลปกแทน และไม่สร้าง avatar ใหม่เอง

ตรวจ FPS, timestamps, จำนวนเฟรม และ source→final mapping ถ้า source เป็น VFR ให้ conform/cut ผ่านแผนหลักก่อนหรือเก็บ timestamps อย่างถูกต้อง ค่าที่ระบุว่า60fpsใน metadata ไม่รับประกันระยะห่างทุกเฟรม อย่าให้ mask เลื่อนไปหนึ่งเฟรมหรือ loop ซ้ำเพื่อให้ยาวเท่าเสียง

## เลือกวิธีที่เครื่องมือรองรับจริง

1. ถ้ามี presenter video พร้อม alpha หรือ RGB+mask ที่รับรองแล้ว ใช้ของเดิมหลังตรวจตรง source/version/FPS
2. ถ้ายังไม่มี ใช้ video matting/segmentation ที่มีอยู่และเหมาะกับพื้นหลังจริง วิธีที่รักษาความต่อเนื่องข้ามเฟรมเหมาะกว่าตัดภาพทีละใบโดยอิสระ ทดสอบช่วงมีผม มือ และการหันหัวก่อนทำทั้งคลิป
3. เก็บ original ไว้ แยก derived cutout/mask ไว้ใน work ของตอน ไม่เปลี่ยนตัวตน สีผิว เสื้อ ใบหน้า หรือการออกเสียง

รูปแบบที่ใช้ได้ขึ้นกับ renderer: วิดีโอ alpha ที่รองรับจริง, PNG RGBA sequence, หรือ RGB video + grayscale mask ที่ใช้ alpha merge และตรง timestamps เก็บ intermediate ที่ไม่บีบอัด alpha เสีย การตั้งชื่อไฟล์ transparent/MOV ไม่พิสูจน์ความโปร่งใส และ MP4 H.264 ปกติไม่ควรใช้เป็น intermediate alpha

หาก engine ใช้ alpha premultiplied/straight ต่างกัน ให้ทำตาม contract ของมันและตรวจขอบที่ composite จริง ไม่แก้ halo ด้วยการ crop ขอบจนผมหรือมือหาย

การตัดพื้นหลังวิดีโอเป็นงาน video processing ไม่ใช่การขอ imagegen แก้ภาพนิ่งของทุกเฟรม ห้ามส่งหนึ่งรูปไปตัดพื้นหลังแล้วใช้แทนทั้ง take ถ้าเครื่องมือในเครื่องยังทำ video cutout ที่ใช้ได้ไม่ได้ ให้รายงานข้อจำกัดและทำ storyboard/assets ส่วนอื่นต่อ โดยไม่ส่ง split-screen/static presenter เป็นงานที่อ้างว่าตรงบรีฟ

## การตรวจ cutout

ตรวจภาพต้นทางเทียบ foreground ที่เวลาเดียวกัน และทดลอง composite บนพื้นสว่าง/มืด:

- ขอบผม หู ไหล่ นิ้วและมือไม่ถูกกิน ไม่เห็นห้องเดิม/green spill/กล่องพื้นหลัง
- Mask ต่อเนื่องเมื่อหันหน้า ขยับมือหรือพูด ไม่กระพริบ/สั่น/มีช่องหายบนหน้าและเสื้อ
- จำนวนเฟรมและ PTS ของ RGB/alpha ตรงกัน ไม่มีภาพต้นเรื่องหยุดนิ่งหรือท้ายเรื่องวนซ้ำโดยไม่อยู่ใน source
- ใบหน้าและปากตรงเสียงจาก take เดิม เทียบต้น กลาง ท้ายและทุกจุดตัด ไม่เลื่อนเสียงเพื่อชดเชย mask ที่ผิด clock

## ตรวจ composition และ final export

### ป้องกัน clock reset และผู้พูดหายที่รอยต่อ

- ตรวจ resolution, pixel format, SAR, color metadata และ PTS ของคลิปย่อยก่อน concat; normalize ค่าที่ต้องตรงกันก่อนประกอบ full-canvas background/RGB/mask การนับเฟรมครบอย่างเดียวไม่ยืนยันว่าผู้พูดอยู่ครบทุกช่วง
- เมื่อ input ทั้งหมด conform เป็น CFR และเริ่ม PTS=0 แล้ว อย่า reset PTS ซ้ำโดยไม่จำเป็นใน foreground graph; การ reinitialize graph จาก parameter change อาจ reset clock แล้วทำให้ overlay หายกลางคลิป ตรวจเฟรมทุก mode และหลังทุกจุดตัดจริง ถ้าปิด reinitialization ต้องยืนยันว่าขนาด/รูปแบบ input ที่ graph ใช้ยังเข้ากันได้
- ตรวจ decoded frame identity ก่อน reuse mask ของ stream ที่เปลี่ยน container/clock; ถ้า RGB ของช่วงใดเปลี่ยน ให้ regenerate mask ช่วงนั้น ไม่ถือว่า frame count เท่ากันคือ mask ตรงภาพ

### ผลงานจริงหลังคำชวนดูผลลัพธ์

- เมื่อเสียงชวนว่าให้ดูงาน/ผลลัพธ์ ต้องมีช่วงเล่นผลงานจริงที่เห็นได้ชัดหลังประโยคนั้น ก่อน CTA ไม่ถือว่าภาพเล็กใต้ผู้พูดระหว่างเกริ่นคือการพาผู้ชมดูผลลัพธ์แล้ว ใช้ฟุตเทจ output จากตอนนั้นจริง เว้นช่วงให้ดูข้อความ/การเคลื่อนไหวได้ และลดหรือเอาผู้พูดออกเฉพาะช็อตโชว์งานที่ไม่มี narration เพื่อไม่บังผลงาน ไม่สร้าง UI หรือผลงานใหม่แทนของเดิม
- ตรวจ export จริงก่อน/หลังคำชวนดูงาน จุดเริ่ม/จบ playback และรอยต่อ CTA เปรียบเทียบภาพผลงานกับ source พร้อมรักษาข้อความสำคัญครบ ถ้าท้ายแจก Prompt ให้เลือกเสียงที่บอกเรื่อง Prompt จริงและให้การ์ดระบุ Prompt ไม่ใช้คำกว้าง ๆ ว่าเนื้อหาแทน ไม่อ้างว่าระบบส่งคอมเมนต์อัตโนมัติถูกตั้งแล้ว

### ซับไทยเมื่อ FFmpeg ไม่มี libass

- ตรวจ filter/encoder ที่ติดตั้งจริงก่อนใช้ subtitles/drawtext; ถ้าไม่มี ใช้ Chromium กับฟอนต์ไทยที่ตรวจแล้วสร้าง PNG RGBA และ frame-exact alpha stream เช่น qtrle หรือ encoder alpha ที่ยืนยันได้ แทนการติดตั้ง engine ใหม่หรือใช้ chromakey กับตัวอักษรโดยปริยาย
- Force-load ฟอนต์ด้วย family/weight ที่ใช้จริงก่อนตรวจ document.fonts.check เมื่อ caption layer ยังว่าง; document.fonts.ready อย่างเดียวไม่โหลดฟอนต์ที่ยังไม่ได้ถูกใช้ ถ้า font/image เป็น local file ให้เปิด HTML ผ่าน file:// origin ที่ตรงกันก่อนโหลด ไม่ setContent บน about:blank แล้วดึง file:// asset เพราะ Chromium อาจปฏิเสธด้วย NetworkError แม้เปิด allow-file-access แล้ว
- งานให้เหมือน EP อ้างอิง ให้ reuse font file และ text renderer/CSS ของ compositor ที่ส่งจริง รวม line-height, bottom anchor, stroke และ shadow ไม่ย้ายไป Pango natural line box แล้วถือว่าชื่อฟอนต์/ขนาดเท่ากันคือเลย์เอาต์เดียวกัน ตรวจการ wrap จริงและลดขนาดเท่าที่จำเป็นเพื่อรักษาจำนวนบรรทัดเดิมและไม่ทับปาก
- จัด PNG ตาม final frame รวม blank ในช่วงเงียบ แล้วตรวจ alpha, จำนวนเฟรม, ภาษาไทยและตำแหน่งจาก final encode ทุก cue รักษา mastered audio ระหว่างแก้ภาพและตรวจ hash ก่อนอ้างว่าเสียงเดิม
- เมื่อเลือกเฟรมตรวจซับจำนวนมากด้วย FFmpeg ให้สร้างผลรวม eq(n,frame) แบบ balanced tree หรือแบ่งชุดเล็ก หาก expression parser ล้มด้วย Cannot allocate memory ให้แก้ selector และตรวจใหม่ ไม่เริ่มเรนเดอร์คลิปที่เสร็จแล้วใหม่เพราะความผิดพลาดของเครื่องมือ QA
- เมื่อ patch รอยต่อบน–ล่าง ให้ reuse upper layer ที่ยังไม่มีซับ แล้ววาง caption PNG เต็มเป็นชั้นสุดท้ายหลัง vstack; อย่าครอปภาพที่ burn-in ซับแล้วมาใช้เฉพาะครึ่งบน เพราะบรรทัดที่สองอาจเลยเส้นแบ่งและหายเมื่อทับกล้องใหม่ ตรวจทุกบรรทัดจาก encoded frame สุดท้ายก่อน cut ไม่ดูแค่ midpoint.
- เมื่อตัดเข้าสู่ CTA หรือประโยครอบใหม่ ให้ตรวจช่วงต้นของ take ที่เก็บด้วย bounded primary ASR และ voice-only waveform ด้วย ไม่ถือว่าคำสรุปแบบลื่นของ Whisper ยืนยันว่าไม่มีคำเริ่มแล้วหยุด เช่น ทุก…เงียบ…ทุกคน; หากพบ restart ให้แยก crop รอบแรก/รอบสมบูรณ์ ตรวจ onset ที่ quantize เป็นเฟรม และเช็ก decoded final seam ว่าประโยคเก่าจบครบ ต่อเข้าประโยคสมบูรณ์เพียงรอบเดียว พร้อม remap ซับและเสียงทุก stem.

เรนเดอร์ sample ที่มี hook → teaching, teaching → explanation และช่วงมือ/ศีรษะขยับที่สำคัญเท่าที่คลิปมี ไม่สร้าง mode ที่ไม่มีในเนื้อหา ดูภาพ encode พร้อมฟังเสียงจริงก่อน render ทั้ง Short

ตรวจฮุค background เต็ม canvas, Title/โลโก้แยกชั้น และคนเป็นวิดีโอ cutout เคลื่อนไหวตรงเสียง คำฮุคอ่านทัน โลโก้ถูกจำนวน/ตัวตนโดยไม่ยัด +/VS หลังฮุคตรวจ template บน–ล่าง: คนพร้อมห้องเดิม ไม่ไดคัต และประโยคบอกสิ่งที่จะสอนครบ โมชั่นครึ่งบนสำหรับแนวคิด ภาพจริงตั้งแต่ look/demo cue ตรวจรวม Prompt/CTA ทุกช่วง ซับไทยครบและไม่ชนใบหน้า/ปุ่ม

ดูเฟรมก่อน/เริ่ม/หลังช่วงสอน ชุดฮุคและ pop-ups ต้องออกแล้วและใช้ source screen จริงตลอด teaching ส่วน explanation ใช้กราฟิกที่ตรงคำพูด ไม่แสดงผลผ่าน/สำเร็จที่บทไม่ได้ยืนยัน

ตรวจ final MP4 ด้าน resolution, FPS, decoded frame count, timestamps/joins, duration และ full decode หยุดแก้/ทดสอบซ้ำเมื่อ checks ที่เกี่ยวข้องผ่านและไม่มีข้อผิดพลาดใหม่ งานภาพ-only รักษา mastered audio เดิมตาม editor หลัก งาน Short ใหม่ใช้เสียง/ซับตามบรีฟ ไม่เปิดเสียงผลงานกับเสียงผู้พูดชนกัน

## ส่งงาน

ส่ง Short MP4 ที่ประกอบและตรวจแล้ว พร้อม editable composition/cue manifest และ derived cutout/mask ที่จำเป็นตามขอบเขตผู้ใช้ เก็บ provenance/asset/tool/quality evidence ในโฟลเดอร์ตอน ไม่ใส่ฟุตเทจผู้ใช้หรือ transcript ลงแพ็กสกิลที่ถ่ายโอนได้

ระบุข้อจำกัดที่ค้างตามจริง การเปิด HTML/การเรนเดอร์ role guide หรือการสร้าง storyboard ไม่ใช่หลักฐานว่าวิดีโอผู้พูดถูกลบพื้นหลังและ export ใช้งานได้ ไม่มีการเผยแพร่/อัปโหลดภายนอกเพิ่มจากการใช้สกิลนี้
